# Tiempos Selima

App para consultar y anotar los tiempos de limpieza de cada casa y local.

- Entrada con correo y contraseña; cada persona nueva necesita aprobación del administrador.
- Los datos viven en Firebase (Firestore) y están protegidos por reglas de seguridad. Este repositorio solo tiene el código de la app, ningún dato.
- Se instala en Android (Chrome → Instalar app) y en iPhone (Safari → Compartir → Añadir a pantalla de inicio).
